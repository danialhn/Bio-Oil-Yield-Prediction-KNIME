## 📌 Project Overview
This repository contains a data science project focused on predicting the yield of bio-oil during the biomass pyrolysis process. The primary goal is to use industrial data to create a predictive model that can assist in optimizing sustainable energy production.

## 🛠 Technical Stack & Tools
- **Platform:** KNIME Analytics Platform
- **Methodology:** Visual Programming (No-code Data Science)
- **Key Nodes used:** Data Reader, Partitioning, Linear Regression Learner, and Regression Predictor

## 📊 Data & Analysis
The project follows a standard data science pipeline:
1. **Data Preprocessing:** Cleaning and normalizing industrial biomass datasets
2. **Feature Engineering:** Identifying key chemical variables influencing oil yield
3. **Modeling:** Implementing Linear Regression to predict outcomes
4. **Evaluation:** Performance was measured using **Mean Absolute Error (MAE)** to ensure model reliability.
